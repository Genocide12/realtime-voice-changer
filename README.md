# realtime-voice-changer

**Голос-подменщик — реалтайм-трансформация голоса и лаборатория звуков, целиком в браузере.**

Микрофон → цепочка DSP-эффектов → наружу идёт уже другой голос. Плюс генератор
процедурных звуков. Без сервера, без сборки, без единой внешней зависимости —
один самодостаточный `index.html`.

Открытая страница (GitHub Pages): **https://genocide12.github.io/realtime-voice-changer/**

## Что умеет

**🎙 Голос (реалтайм)**
- 8 пресетов: Чистый, Робот, Монстр, Демон, Белка, Радио, Космонавт, Гибрид + кубик «Рандом»;
- ручная цепочка: гранулярный питч-шифтер ±24 полутона, ринг-модуляция, tanh-перегруз,
  НЧ/ВЧ-фильтры, реверб (генерируемый импульс), эхо с обратной связью, компрессор;
- мониторы входа/выхода, кнопка «Оригинал A/B», запись результата в `.webm`.

**🎛 Лаборатория звуков**
- 12 пэдов: Лазер, Взрыв, Кик, Сирена, Бипы, Металл, Гудок, Вжух, Падение, Гул,
  Плазма, Морзе — каждый синтезируется с нуля (осцилляторы, шум, энвелопы, свипы)
  и каждый раз чуть отличается;
- ручки характера: высота, яркость, длительность, реверб; клавиши `1–9, 0, Q, W`;
- запись лаборатории в `.webm`.

Звук никуда не отправляется: вся обработка — локально в браузере (AudioWorklet + Web Audio API).

## Как устроено

```
микрофон → AudioWorklet (питч + ринг-мод + перегруз)
        → highpass → lowpass
        → реверб (ConvolverNode, процедурный IR, wet/dry)
        → эхо (Delay + feedback + фильтр)
        → компрессор → выход
```

Питч-шифтер — двухголовочный гранулярный с перекрёстным `sin²`-окном (сумма окон = 1,
нет «дыхания» громкости), работает внутри AudioWorklet, задержка ~21 мс.

## Честная граница возможности

DSP в браузере меняет **характер** голоса (высота, тембр-эффекты, пространство) —
это и есть «другой голос». Клонирование тембра конкретного человека (ML-модели
типа RVC) требует GPU-сервера, в статическую страницу это не упаковать: смотри
[w-okada/voice-changer](https://github.com/w-okada/voice-changer) и
[Plachtaa/seed-vc](https://github.com/Plachtaa/seed-vc) — они дают качество уровня
стримов, но это отдельная серверная сборка.

## Версия для ноутбука (один exe)

`desktop/main.go` — обёртка на Go: встраивает `index.html` в бинарник, поднимает
локальный сервер на `127.0.0.1` (микрофон разрешён на localhost), сам открывает
браузер. Ничего устанавливать не нужно, работает офлайн, звук никуда не идёт.

- Готовый файл: **`VoiceChanger.exe`** (Windows x86-64, ~6 МБ) — лежит в
  [Releases](https://github.com/Genocide12/realtime-voice-changer/releases);
- двойной клик → появится консоль с адресом → браузер откроется сам;
- выключение: закрыть окно консоли (или Ctrl+C);
- Windows SmartScreen предупредит о неподписанном exe — «Подробнее → Выполнить
  в любом случае»;
- собрать самому: `cd desktop && GOOS=windows GOARCH=amd64 go build -trimpath
  -ldflags "-s -w" -o VoiceChanger.exe .` (нужен Go 1.21+; сборка проверена на Go 1.27).

## Локальный запуск

```bash
git clone https://github.com/Genocide12/realtime-voice-changer.git
cd realtime-voice-changer
python3 -m http.server 8080
# открыть http://localhost:8080 (микрофон работает на localhost и по HTTPS)
```

## Этика

Используй свой голос или голос с явного разрешения владельца. Не применяй подмену
голоса для обмана там, где от «кто говорит» зависит решение.
