# realtime-voice-changer

**Голос-подменщик: real-time voice conversion за один вечер.**

Интерактивный гайд + демо-стенд: твой голос подавляется на входе компьютера, и наружу —
в Discord, Zoom, игру или стрим — идёт уже другой голос (или гибрид).

Открытая страница (GitHub Pages): **https://genocide12.github.io/realtime-voice-changer/**

## Что внутри

- `index.html` — самодостаточная страница (без сборки, фреймворков и внешних скриптов):
  - принцип работы схемы «микрофон → RTVC-движок → виртуальный микрофон»;
  - требования к железу и софту;
  - сборка «Вариант Б» в 6 шагов (VB-Cable → w-okada voice-changer → RVC-модель →
    маршрутизация → Discord/Zoom → тест);
  - интерактивный калькулятор задержки цепочки (чанк, драйвер, инференс, выходной буфер);
  - живое DAF-демо на Web Audio API: микрофон возвращается в наушники с регулируемой
    задержкой 0–600 мс — можно заранее почувствовать, с чем придётся жить мозгу;
  - таблица граблей и решений, приёмы гибридов голосов, заметки об этике.

## Стек, о котором идёт речь

| Компонент | Роль |
| --- | --- |
| [w-okada/voice-changer](https://github.com/w-okada/voice-changer) | движок real-time конвертации голоса |
| RVC-модель (`.pth` + `.index`) | целевой голос: готовая модель сообщества или своя (10–30 мин записи) |
| [Seed-VC](https://github.com/Plachtaa/seed-vc) | zero-shot: голос из сэмпла 1–30 с без обучения |
| [VB-Cable](https://vb-audio.com/Cable/) | виртуальный аудиокабель — «фейковый микрофон» для приложений |
| VoiceMeeter Banana | альтернатива CABLE с микшером и роутингом |

Минимальное железо: NVIDIA GPU с 4 ГБ VRAM (комфорт — 6+), Windows 10/11, наушники
(закрытые — лучше), любой микрофон.

## Локальный запуск

Файл `index.html` полностью автономен — просто открой его в браузере.
DAF-демо с микрофоном работает по HTTPS или на `localhost`:

```bash
git clone https://github.com/Genocide12/realtime-voice-changer.git
cd realtime-voice-changer
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Этика и закон

Клонируй только свой голос или голос с явного письменного разрешения владельца.
Не используй подмену голоса для обмана там, где от «кто говорит» зависит решение
(деньги, доступ, доверие). Помечай синтетические записи при публикации.
