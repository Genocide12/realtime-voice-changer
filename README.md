# realtime-voice-changer

**Голос-подменщик — реалтайм-трансформация голоса, генератор звуков, синтезатор и синтез речи.**

Микрофон → цепочка DSP-эффектов → наружу идёт уже другой голос. Рядом — генератор
процедурных звуков, играемый синтезатор и озвучка текста голосами системы.
Без внешних зависимостей: веб-версия — один самодостаточный `index.html`,
десктоп-версия — один `VoiceChanger.exe`, который сам всё запускает и работает
в **своём окне**, без браузера.

Веб-версия (GitHub Pages): **https://genocide12.github.io/realtime-voice-changer/**
Десктоп (Releases): **https://github.com/Genocide12/realtime-voice-changer/releases**

## Что умеет

**🎙 Голос (реалтайм)**
- 20 голосов-пресетов: Робот, Монстр, Демон, Белка, Фея, Автотюн, Радио, Телефон,
  Призрак, Пришелец, Под водой, Пещера, Мегафон, Шёпот, Хор, Гибрид, Пчела,
  Вейдер, Глитч + кубик «Рандом» и сохранение своей настройки «Свой»;
- «Спеть системным голосом»: любой установленный в Windows голос озвучивает текст
  и проходит через текущую DSP-цепочку (в десктоп-версии);
- ручная цепочка: гранулярный питч-шифтер ±24 полутона, **автотюн** (детектор высоты
  тона + подстройка под ближайшую ноту), ринг-модуляция, tanh-перегруз, биткрашер
  (битность + прореживание), вибрато, тремоло, хор, НЧ/ВЧ-фильтры, шумоглушитель,
  реверб (процедурный импульс), эхо с обратной связью, компрессор;
- мониторы входа/выхода, кнопка «Оригинал A/B», запись результата в `.webm`.

**🎛 Генератор звуков — 35 рецептов**
- природа: Гром, Дождь, Ветер, Океан, Огонь;
- ударные: Кик, Снейр, Хэт, Хлопок;
- техника и космос: Лазер, Взрыв, Плазма, НЛО, Разряд, Металл, Мотор, Вертолёт, Пар;
- сигналы: Сирена, Сигнализация, Бипы, Гудок, Морзе;
- живое: Сердце, Часы, Птица, Сверчок, Мяу, Гав, Пузыри, Капля;
- фактура: Вжух, Падение, Гул.
- каждый звук синтезируется с нуля (осцилляторы, шум, энвелопы, свипы) и каждый раз
  чуть отличается; ручки характера: высота, яркость, длительность, реверб;
  запись в `.webm`.

**🎹 Синтезатор**
- играемая клавиатура 2 октавы (мышь или `Z S X D C V G B H N J M`, октава `←`/`→`);
- волна (пила/квадрат/треугольник/синус/жирная пила ×3), детюн второго осциллятора,
  атака/релиз, резонансный фильтр, эхо и реверб; запись в `.webm`.

**🗣 Синтез речи**
- озвучка любого текста голосами, установленными в Windows/браузере,
  с выбором голоса, скоростью, тоном и громкостью;
- в десктоп-версии системные голоса (SAPI) рендерятся в WAV и проходят
  **через полную цепочку эффектов из раздела «Голос»**: 19 пресетов и все слайдеры;
- кнопка «Прослушать голос» (чистый прогон), корректная остановка без ошибки
  «interrupted».

**🎹 Синтезатор — полная клавиатура**
- 26 клавиш: белые — `LShift Z X C V B N M , . / RShift Num1 Num2 Num3`,
  чёрные — `A S D F G H J K L ; '` (физические кнопки, работают в любой раскладке);
- долгое нажатие на пэд в «Генераторе звуков» → привязка любой кнопки
  (Esc — снять), сохраняется между запусками.

**🧠 Нейро-голос (только десктоп)**
- вкладка с автоустановкой [w-okada/voice-changer](https://github.com/w-okada/voice-changer):
  скачивание, распаковка, запуск и встраивание интерфейса в окно программы;
- настоящий ИИ-клон тембра (RVC): первый запуск ~1 ГБ, нужен интернет.

Звук никуда не отправляется: вся обработка — локально (AudioWorklet + Web Audio API).

## Как устроено

```
микрофон → AudioWorklet:
            шумоглушитель → питч-шифтер (ручной ±24 пт / автотюн)
            → ринг-модуляция → tanh-перегруз → биткрашер
        → вибрато (Delay + LFO) → highpass → lowpass
        → тремоло → хор (2× Delay + LFO, параллельно)
        → реверб (ConvolverNode, процедурный IR, wet/dry)
        → эхо (Delay + feedback + фильтр, петля изолирована от выхода)
        → компрессор → выход
```

- Питч-шифтер — двухголовочный гранулярный с перекрёстным `sin²`-окном (сумма окон = 1,
  нет «дыхания» громкости), задержка ~21–43 мс.
- Автотюн: каждые ~43 мс автокорреляционный детектор высоты тона (децимация ×4,
  параболическая доводка пика) → ratio подстраивается под ближайшую ноту со сглаживанием.
- Эхо разведено в отдельную петлю с выходом через отдельный узел — обратная связь
  не может превысить 1 и уйти в самовозбуждение.

## Проекты, у которых взяты техники

- [mdn/voice-change-o-matic](https://github.com/mdn/voice-change-o-matic) — живая цепочка эффектов
  на микрофоне + визуализация;
- [olvb/phaze](https://github.com/olvb/phaze) — питч-шифтер как AudioWorklet, реалтайм без хаков;
- [cutterbl/soundtouchjs-audio-worklet](https://github.com/cutterbl/soundtouchjs-audio-worklet) —
  гранулярная смена высоты в worklet (порт SoundTouchJS);
- [grumdrig/jsfxr](https://github.com/grumdrig/jsfxr) — процедурные SFX: энвелопы, свипы, шум —
  подход генератора звуков;
- [GoogleChromeLabs/web-audio-samples](https://github.com/GoogleChromeLabs/web-audio-samples) —
  паттерны AudioWorklet-процессоров;
- [Tonejs/Tone.js](https://github.com/Tonejs/Tone.js) — паттерн wet/dry-роутинга эффектов.

## Честная граница возможности

DSP меняет **характер** голоса (высота, тембр-эффекты, пространство) — это и есть
«другой голос». Клонирование тембра конкретного человека (ML-модели типа RVC)
требует GPU: смотри [w-okada/voice-changer](https://github.com/w-okada/voice-changer)
и [Plachtaa/seed-vc](https://github.com/Plachtaa/seed-vc) — качество уровня стримов,
но это отдельная серверная сборка.

## Версия для ноутбука (один exe, без браузера)

`desktop/` — обёртка на Go: встраивает `index.html` в бинарник, поднимает локальный
сервер на `127.0.0.1` (микрофон разрешён на localhost) и открывает **нативное окно
WebView2** (движок Edge, уже встроен в Windows 10/11) — браузер не запускается,
страница никуда не выходила. Права на микрофон выдаются автоматически при старте.
Пока страница грузится — анимированный сплэш-экран (окно не мигает белым).
Дополнительно к сайту программа умеет: системные голоса SAPI для «пения» и речи
с эффектами, и запуск нейро-движка w-okada для ИИ-подмены голоса.

- Готовый файл: **`VoiceChanger.exe`** (Windows x86-64, ~9.5 МБ) — в
  [Releases](https://github.com/Genocide12/realtime-voice-changer/releases);
- двойной клик → открывается окно программы → нажми «🎤 Включить микрофон»;
- если WebView2 Runtime вдруг отсутствует — программа сама откроется в браузере;
- SmartScreen предупредит о неподписанном exe: «Подробнее → Выполнить в любом случае»;
- выключение: закрыть окно программы.

Собрать самому (нужен Go 1.21+, проверено на 1.27):

```bash
git clone https://github.com/Genocide12/realtime-voice-changer.git
cd realtime-voice-changer/desktop
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H windowsgui -s -w" -o VoiceChanger.exe .
# иконка: go run github.com/akavel/rsrc@latest -ico icon.ico -arch amd64 -o rsrc_windows_amd64.syso
```

## Локальный запуск веб-версии

```bash
python3 -m http.server 8080
# открыть http://localhost:8080 (микрофон работает на localhost и по HTTPS)
```

## Этика

Используй свой голос или голос с явного разрешения владельца. Не применяй подмену
голоса для обмана там, где от «кто говорит» зависит решение.
